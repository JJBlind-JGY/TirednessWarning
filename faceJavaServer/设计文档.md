# 基于面部表情的疲劳识别项目设计文档
## 1.项目概述
基于面部表情的疲劳识别项目是一个结合了 Vue、Spring Boot 和 PyTorch 技术的综合性项目，其核心目标是对人脸疲劳检测相关的视频数据进行高效处理。系统从前端接收用户上传的视频文件，将视频拆分为一帧一帧的图片，发送给预训练好的模型进行疲劳分析，并将处理结果通过 WebSocket 实时推送给前端进行展示，为用户提供直观的疲劳检测信息。
## 2.系统架构设计
系统主要由前端、后端和模型端三个部分构成，各部分相互协作，共同完成疲劳识别的任务。
### 2.1 整体架构
### 2.1.1 前端
前端为用户提供了简洁友好的交互界面，主要包含两个核心模块：
- 视频上传模块：该模块为用户提供了方便快捷的视频上传接口，允许用户选择并上传想要分析的视频文件。同时，在上传成功后，会提取并展示视频的基本信息，如帧宽度、帧高度等，使用户对上传的视频有更清晰的了解。
- 数据展示模块：以直观的方式展示视频的分析结果，例如通过折线图展示疲劳指数的变化趋势，同时显示面部危险等级和是否需要停工等信息，帮助用户快速掌握视频中的疲劳情况。
### 2.1.2 后端
后端采用分层架构设计，各层职责明确，有效降低了系统的耦合度，提高了系统的可维护性和可扩展性。
- 表现层：负责接收前端的请求，处理用户的输入和输出，主要由控制器（Controller）组成。
- 业务逻辑层：负责处理具体的业务逻辑，如视频处理、消息推送等，主要由服务（Service）组成。
- 数据访问层：负责与外部系统进行数据交互，如与模型服务器进行通信，主要由工具类（Utils）组成。
- 工具层：提供一些通用的工具类和方法，如文件处理、JSON 处理等。
### 2.1.3 模型端
模型端负责接收后端处理好的视频帧数据，并利用已训练好的模型对其进行疲劳分析，将分析结果发送给后端。模型端采用 PyTorch 框架，确保模型的高效运行和准确预测。
### 2.2 模块划分
根据系统的功能需求，将系统划分为以下几个模块：
- 视频上传模块：包括前端负责上传视频文件的模块，以及后端负责接收前端上传的视频文件，并将视频流传递给视频处理模块。
- 视频处理模块：将视频流处理为一帧一帧的图片，并将图片数据发送给模型服务器进行处理。
- 视频分析模块：模型端接收视频帧后，利用已训练好的模型，对视频帧进行分析。
- 模型通信模块：后端与模型端相互通信的一个模块，后端发送处理好的视频帧，模型端发送的处理结果,并将结果传递给消息推送模块。
- 消息推送模块：将模型服务器返回的处理结果通过 WebSocket 推送给客户端。
- 数据展示模块：用于展示视频的分析结果，尽可能直观的让用户去对处理好的结果进行观察。
# 3.功能模块设计
## 3.1 视频上传模块
### 3.1.1 功能描述
前端提供视频文件的上传接口，支持多种视频格式（如 MP4、OGG、FLV、AVI、WMV、RMVB 等）。后端接收前端上传的视频文件，并将视频流传递给视频处理模块。
### 3.1.2 实现方式
使用 HTML5 的控件结合 Vue.js 实现视频文件的选择和上传。使用 Element UI 的 el-upload 组件来美化上传界面。在选择文件时，对文件类型进行初步验证，确保选择的是支持的视频格式。
后端使用 Spring Boot 的 MultipartFile 类来处理文件上传，通过 @RequestPart 注解获取上传的文件，通过 @RequestParam 注解获取用户 ID。
## 3.2 视频处理模块
### 3.2.1 功能描述
将视频流处理为一帧一帧的图片，并将图片数据发送给模型服务器进行处理。
### 3.2.2 实现方式
使用 JavaCV 库来处理视频流，通过 FFmpegFrameGrabber 类来抓取视频帧，将视频帧转换为 BufferedImage 对象，再将 BufferedImage 对象转换为 JPEG 格式的字节数组，最后将字节数组发送给模型服务器。
## 3.3 视频分析模块
### 3.3.1 功能描述
模型端接收视频帧后，利用已训练好的模型，对视频帧进行疲劳分析，输出疲劳等级和疲劳指数。
### 3.3.2 实现方式
模型端使用 PyTorch 框架加载预训练好的模型，对输入的视频帧进行预处理（如缩放、归一化等），然后进行模型推理，得到疲劳等级和疲劳指数。
## 3.4 模型通信模块
### 3.4.1 功能描述
后端与模型端相互通信的一个模块，后端发送处理好的视频帧，模型端发送的处理结果,并将结果传递给消息推送模块。
### 3.4.2 实现方式
使用 Java-WebSocket 库来实现 WebSocket 通信，通过 WebSocketClient 类来连接模型服务器，重写 onMessage 方法来处理模型服务器返回的消息，将消息解析为 JSON 对象，提取出疲劳等级和疲劳指数，调用消息推送模块的方法将结果推送给客户端。
## 3.5 消息推送模块
### 3.5.1 功能描述
将模型服务器返回的处理结果通过 WebSocket 推送给客户端。
### 3.5.2 实现方式
以直观的方式展示视频的分析结果，包括疲劳指数变化曲线、面部危险等级和是否需要停工等信息。
## 3.6 数据展示模块
使用 ECharts 库来绘制疲劳指数变化曲线，通过 Vue.js 动态更新图表数据。同时，使用 Element UI 组件展示面部危险等级和是否需要停工等信息，根据疲劳等级的不同，显示不同的颜色和提示信息。
