# 1.概述
本接口设计文档涵盖了基于面部表情疲劳项目中的核心接口，主要用于处理人脸疲劳检测相关的视频数据上传以及实时推送处理结果。这些接口通过 HTTP 和 WebSocket 协议实现，确保了前端、后端以及模型之间的数据交互和实时通信。
# 2.接口列表
## 2.1 前后端接口
### 2.1.1 视频上传接口
接口名称：video_upload
接口地址：POST /faceDetectService/video_upload
功能描述：接收前端上传的视频文件和用户 ID，将视频流传递给后端进行处理。
请求参数：

| 参数名    | 类型            | 是否必传 | 描述      |
|--------|---------------|------|---------|
| file   | MultipartFile | 是    | 上传的视频文件 |
| userId | String        | 是    | 用户 ID   |
返回参数：

| 参数名  | 类型      | 描述                  |
|------|---------|---------------------|
| code | Integer | 状态码，200 表示成功，其他表示失败 |
| msg  | String  | 消息描述                |
### 2.1.2 疲劳检测结果实时推送接口
接口名称：face_fatigue_push
接口地址：WebSocket /topic/face_fatigue/{userId}
功能描述：将模型服务器处理后的疲劳等级、疲劳指数、情绪类型等结果实时推送给客户端。
后端消息发送参数说明：
| 参数名          | 类型     | 描述                   |
|--------------|--------|----------------------|
| userId       | String | 用户 ID                |
| fatigueRank  | String | 疲劳等级，取值范围为 "0" - "3" |
| fatigueIndex | String | 疲劳指数，取值范围为 0 - 10    |
| timestamp    | Long   | 消息发送的时间戳             |
| emotionCat   | String | 情绪类型，取值为"虚弱"、"疲劳"、"紧张"、"焦躁"、"其它" |
| score        | String | 本次检测准确率，格式为百分比（如"95.2%"） |
| rate         | String | 综合检测准确率，格式为百分比（如"93.5%"） |


## 2.2 后端与模型接口
### 2.2.1 视频帧分析接口
接口名称：analyze_frame
接口地址：WebSocket /model/analyze
功能描述：接收后端发送的视频帧图像数据，进行疲劳分析，返回分析结果。
后端消息发送参数：

| 参数名 | 类型 | 是否必传 | 描述 |
|--------|-------|------|---------------------|
| userId | String | 是 | 用户 ID |
| frame | String | 是 | Base64 编码的图像数据（JPEG格式） |

模型消息发送参数：

| 参数名 | 类型 | 描述 |
|----------|---------|---------------------|
| userId | String | 用户 ID |
| arousal | String | 唤醒度值（用于计算疲劳指数） |
| emotionId | Integer | 情绪ID，取值为0（虚弱）、1（疲劳）、2（紧张）、3（焦躁） |
| score | String | 本次检测的原始准确率值 |

## 一、前后端接口消息示例
### 1.1 视频上传接口（POST /faceDetectService/video_upload）
- **请求示例**（multipart/form-data格式）：
  ```
  --boundary
  Content-Disposition: form-data; name="file"; filename="test_video.mp4"
  Content-Type: video/mp4
  
  [视频文件二进制数据]
  --boundary
  Content-Disposition: form-data; name="userId"
  
  user123456
  --boundary--
  ```

- **响应示例**（JSON格式）：
  ```json
  {
    "code": 200,
    "msg": "视频上传成功，正在处理"
  }
  ```

### 1.2 疲劳检测结果实时推送接口（WebSocket /topic/face_fatigue/{userId}）
- **后端推送消息示例**（JSON格式）：
  ```json
  {
    "userId": "user123456",
    "fatigueRank": "2",
    "fatigueIndex": "7.5",
    "timestamp": 1695876321000,
    "emotionCat": "疲劳",
    "score": "95.2%",
    "rate": "93.5%"
  }
  ```
